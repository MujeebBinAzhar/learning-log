## Weekly rhythm (~8 hours)

| Day | Time | What |
| --- | --- | --- |
| Mon–Fri | 1 hour | 35 min learn + 25 min type and run the code yourself |
| Saturday | 2 hours | Build the phase project |
| Sunday | 30–45 min | Write the weekly log + 1 DSA problem (or rest) |

## AI rules

1. Phases 0–2: AI as a tutor only — hints and explanations, never solutions. Inline autocomplete OFF.
2. From Phase 3: struggle 30 minutes before asking AI.
3. Never commit code I can't explain line by line.
4. Debug by hand first: error → stack trace → debugger → my own guess → then ask.
5. From Phase 8: use AI fully — because I can now judge its output.

link them in the phase README.

## Getting reviewed

Push to GitHub, then share the repo link or code with Claude (in the "skills growth" project) and ask for a
senior-engineer review: issues and questions, not rewrites.
